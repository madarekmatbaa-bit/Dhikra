# نموذج سماع التلاوة

`asr-model.yml` ينسخ نموذج سماع التلاوة إلى الإصدار `asr-3` من هذا المستودع، ليُنزّله
التطبيق عند أول استعمال من مصدر ثابت لا يتغير.

النموذج: Zipformer متدفق من Quran-Lab يُخرج أصوات القراءة (251 رمزاً)، بصيغة ONNX مصغّرة.
رخصته NPL-1.2 (`licenses/NPL-1.2.txt`): يُستعمل ويُوزَّع مجاناً، ولا يُباع ولا تُباع ميزة تقوم عليه.

- `quran-zipformer-a.int8.onnx`: النموذج الرسمي v3.
- `quran-zipformer-b.int8.onnx`: نسخة tilawa المعدّلة بتسجيلات هواة أكثر.

لتشغيله من جديد عدّل `version.txt` هنا.
